## HARD CONSTRAINTS (violating these makes output invalid, not just imperfect)
1. Treat "-- Unbranded --", "-- No Unilog Brand --", "-- No DIB Brand --" (and any
   "-- No X --" pattern) as NULL, everywhere, from the moment you load the data.
2. Attribute values must come from the LOV's Normalized Values for the row's
   Classpath. Manufacturer/brand names must exactly match the approved list —
   symbols and casing included. Units must use the approved UOM abbreviation.
   NEVER invent a value that isn't traceable to an input field or a lookup table.
3. Product data must come from the manufacturer's own site/documentation only.
   Marketplaces and distributor sites are explicitly excluded as sources — if you
   add a web-fetch enrichment step, enforce this domain check before accepting
   any fetched content.
4. It's fine — and rewarded — for output fields to be blank when you can't derive
   them confidently. Do not pad rows with guessed values to look complete. Flag
   uncertain fields instead of guessing.

## PIPELINE STRUCTURE (build as separate, individually testable modules —
run in this order)
  0_ingest.py           Load & clean all source files into cached lookup tables
                         (parquet). Apply the placeholder-nulling rule here, once.
  1_dedup.py             Exact-key + fuzzy near-duplicate detection on the 1,000
                         working rows (rapidfuzz, report duplicate clusters).
  2_manufacturer_brand.py  Fuzzy-resolve Part_Manuf / brand columns to canonical
                         MANUFACTURER_NAME / BRAND_NAME using rapidfuzz against
                         the 27k master list; fall back to manufacturer name when
                         no brand exists; log match score per row.
  3_classify.py           Classpath assignment: embedding shortlist (top-k) over
                         the LOV's Classpath/Leaf Node text, then final selection.
                         Constrain strictly to the scoped category's valid leaf
                         nodes for this build.
  4_attributes.py         Structured attribute extraction from Part_Desc,
                         constrained to the Classpath's valid Attribute Labels/
                         Values from the LOV (JSON-schema-constrained LLM call,
                         temperature 0) plus a regex pass for high-confidence
                         numeric patterns (voltage, amperage, sizes).
  5_normalize.py           Unit normalization via the UOM lookup table; decimal↔
                         fraction conversion via Decimal_Fraction; casing/
                         hyphenation per the house-style rules sheet.
  6_describe.py            Template-first construction of each required
                         description field from resolved structured fields, using
                         the exact formulas/char-limits/casing rules from the
                         content guidelines doc. LLM used only to phrase/order,
                         never to introduce new facts.
  7_score_confidence.py    Per-row/per-field confidence scoring + review flag.
  8_assemble_output.py     Map everything into the exact 252-column Delivery
                         Format schema (correct column names/order — read them
                         from the "Delivery Format" sheet header, do not
                         hand-type them) and write both a CSV/XLSX deliverable
                         and a parallel per-SKU JSONL audit trail (which stage
                         produced each field, from what evidence, confidence).
  scripts/evaluate.py      Standalone, re-runnable: field-level accuracy vs the
                         200-item ground truth (exact + fuzzy match rates per
                         field), character-limit compliance %, % of attribute
                         values found in the LOV. Print a clean summary table.
